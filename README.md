# Scientific Calculator

Учебное браузерное приложение для выполнения научных вычислений.

## Стек

- Next.js App Router
- React
- TypeScript
- SCSS Modules
- Font Awesome
- Vitest
- pnpm


## Запуск

Установить зависимости:

```bash
pnpm install
```

Запустить сервер разработки:

```bash
pnpm dev
```

Открыть http://localhost:3000.

## Проверки

Проверить типы:

```bash
pnpm exec tsc --noEmit
```

Проверить код через ESLint:

```bash
pnpm exec eslint .
```

Собрать приложение:

```bash
pnpm build
```

Запустить собранное приложение:

```bash
pnpm start
```


Вычисления реализованы через рекурсивный парсер без eval().
Логика вычислений отделена от компонентов React.

Тернарные операторы используются для выбора арифметического
действия, обработки знака, вычисления степени и условного
отображения элементов интерфейса.

## Правила вычислений

- Процент определяется как x% = x / 100.
- 200 × 10% = 20.
- 100 + 10% = 100.1.
- Степени вычисляются справа: 2 ^ 3 ^ 2 = 512.
- -2 ^ 2 = -4, а (-2) ^ 2 = 4.
- Умножение перед скобками указывается явно: 2 × (3 + 4).
- Корень вводится как sqrt(81) и отображается как √(81).

## Ограничения

- Вычисления выполняются в действительных числах.
- Используется стандартная точность JavaScript Number.
- Результат отображается с округлением до 12 значащих цифр.
- Максимальная длина вычисляемого выражения — 500 символов.
- История хранится локально в браузере и не синхронизируется.
- При недоступности localStorage история работает только
  в памяти до перезагрузки страницы.
